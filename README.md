## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->
این پروژه یک صفحه فرود دو نیمه‌ای (Split Landing Page) تعاملی است. صفحه به دو بخش مساوی (برای محصولات یا برندهای مختلف مانند پلی‌استیشن و ایکس‌باکس) تقسیم شده است؛ با بردن نشانگر ماوس روی هر طرف، آن بخش گسترش یافته و بخش دیگر جمع می‌شود تا تمرکز کاربر کاملاً روی آن محصول قرار گیرد.

## ویژگی ها  
<!-- Features : استاندارد --> 
- طراحی واکنش‌گرا و دو‌بخشی با استفاده از Flexbox و CSS Custom Properties
- انیمیشن‌های نرم و روان با ترنزیشن‌های عرضی (`transition: width`)
- لایه‌گذاری پیشرفته با پس‌زمینه و گرادیان‌های رویی (`::before`)
- تعامل‌پذیری روان با رویدادهای `mouseenter` و `mouseleave` در جاوااسکریپت
- کدنویسی تمیز، ساختاریافته و کاملاً بدون وابستگی به کتابخانه‌های خارجی

## Project Description 📌
<!-- Standard : Project Description  -->
This project implements an interactive split landing page. The viewport is divided equally between two featured items (PlayStation and Xbox). Hovering over either side dynamically expands that section while compressing the other, creating an engaging focus effect.


---
---
---

## Features 🌏
<!-- Standard : features  -->
- Responsive split layout utilizing Flexbox and CSS Custom Properties
- Smooth and fluid transition effects on width modifications
- Advanced overlay and background styling with pseudo-elements (::before)
- Dynamic interactivity powered by mouseenter and mouseleave JS events
- Clean, modular, and dependency-free codebase
